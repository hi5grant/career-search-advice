# Contributing

Suggestions and corrections are welcome. This repository is a public guide; do not submit private career histories, resumes, contact details, employer-confidential information, or proprietary materials.

## How to contribute

1. Open an issue describing the proposed improvement, or submit a pull request.
2. Keep changes focused and evidence-based.
3. Use fictional examples or clearly labeled hypotheticals.
4. Do not claim that a ChatGPT feature, GitHub permission, or UI path is guaranteed to exist for every account.
5. Explain meaningful changes in the pull request.

All pull requests should be reviewed and approved by the repository owner before merging. The owner may close contributions that are out of scope or unsafe.
