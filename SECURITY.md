# Security Policy

This repository is public. Do not submit:
- Personal resumes, phone numbers, email addresses, home addresses, or other personal data.
- Passwords, API keys, access tokens, private keys, or credentials.
- Customer/member information or regulated data.
- Confidential employer documents, source code, architecture diagrams, or internal-only details.

If you find sensitive information, do not reproduce it in an issue or pull request. Contact the repository owner privately through GitHub.
