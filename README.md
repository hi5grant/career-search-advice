# Career Search Advice

A practical, repeatable system for turning years of work experience into a credible career inventory, evaluating opportunities, and creating targeted resumes—with ChatGPT and GitHub.

**[Open the public guide](https://hi5grant.github.io/career-search-advice/)**

This repository is the public playbook. Your personal career history belongs in a separate **private** repository.

## The workflow

1. **Interview:** reconstruct roles and projects through targeted questions.
2. **Inventory:** build a detailed, factual master career inventory.
3. **Connect:** use the ChatGPT GitHub integration with a private career workspace.
4. **Research:** investigate company business models, financial health, strategy, and stability.
5. **Evaluate:** compare job requirements against evidence in your inventory.
6. **Tailor:** generate a concise, ATS-readable resume from verified facts.
7. **Improve:** update the inventory as you remember details and learn from interviews.

## Quick start

1. Create a private repository named `career-tools`.
2. Add `career/master-career-inventory.md`.
3. Connect GitHub to ChatGPT and authorize access only to the repository you need.
4. Start with [the inventory interview prompt](templates/inventory-interview.md).
5. Keep the inventory factual and comprehensive; tailor resumes only after checking claims.
6. Organize applications under one Title Case company folder per employer, with a separate `job-roles/YYYY-MM - Role Title/` folder for every distinct posting. See the [recommended workspace layout](docs/github-setup.md).

## Core principles

- Accuracy beats impressive wording.
- Separate personal projects from paid employment.
- Distinguish your contribution from team accomplishments.
- Never turn estimates into precise metrics.
- Keep uncertainty visible in the private inventory.
- Treat private-company financial estimates as estimates, not audited results.
- Review every resume claim as if an interviewer will challenge it.
